Windows x86_64 portable build, macOS Intel and Apple Silicon app bundles, and Linux x86_64 portable archive
Git tag: `4.0.0-beta.6`

This is the first test release from [Amadou-dot's fork](https://github.com/Amadou-dot/juxtopposed-vlc), based on [dsojevic's implementation](https://github.com/dsojevic/juxtopposed-vlc) of [Juxtopposed](https://www.juxtopposed.com/)'s [VLC redesign](https://www.figma.com/community/file/1691465999134370980/vlc-redesign).

**Full Changelog:** https://github.com/Amadou-dot/juxtopposed-vlc/compare/619b57dd8597605500aed1845d182bd37742dc4e...4.0.0-beta.6

**Changes from the fork's starting point:**

- Distinguish Repeat All from Repeat Current Item in the queue, including the current-item "1" badge and mode-specific labels.
- Add 16:9 queue thumbnails alongside filenames and durations, with an orange indicator for the playing item and a consistent placeholder while previews load or are unavailable.
- Use existing artwork when available. For local videos without artwork, generate representative frames in the background and retry later positions when the first frame is nearly black.
- Request previews for visible rows, limit generation to one worker, and cache results in memory and on disk. Bound memory, disk use and generation time, and cancel obsolete requests when items leave view.
- Check for updates from `Amadou-dot/juxtopposed-vlc`, validating release and download links against this fork. Downloads and installation remain manual.

**Use:**

- Close earlier VLC windows before starting this build. Keep each download's complete contents together.
- Linux: extract `vlc-juxtopposed-4.0.0-beta.6-linux-x86_64.tar.gz`, then run `AppDir/AppRun`. The build requires glibc 2.35 or later and GLIBCXX 3.4.30 or later (Ubuntu 22.04 or equivalent); no FUSE installation is needed.
- Windows 10 (1809 or later) / Windows 11, x64: extract `vlc-juxtopposed-4.0.0-beta.6-win64.zip`, then open `vlc-win64/vlc.exe`. The `portable` folder stores settings beside the app. Copy previous portable settings only while VLC is closed.
- macOS: choose `macos-arm64` for Apple Silicon or `macos-x86_64` for Intel. Extract the ZIP and open `VLC Juxtopposed.app`. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it.
- Install this fork's build manually the first time: builds from the original repository still check that repository for updates. This build will check the fork for subsequent releases.
- Verify downloads against `SHA256SUMS.txt`. The table below identifies the source commit for each package; detailed build metadata remains in the workflow artifacts.

**Current limits:**

- This is an experimental prerelease. Test playback, queue scrolling and switching between clips with your own media.
- Video-frame generation is limited to local regular files. Unsupported media and failed previews retain the placeholder; remote items can display existing artwork.
- Windows executables have no trusted publisher signature. Mac apps are ad-hoc signed without a Developer ID signature or Apple notarization; operating systems may warn or block the first launch.
- Mac downloads are separate native builds. Build metadata records the minimum supported macOS version. Linux uses the host's graphics drivers and desktop/audio services.
- The media library database must be on a local drive. Other limitations of the upstream redesign still apply.
